# Compact connected abelian groups with no small subgroups are tori

An informal account of Oliver Nash's
[Lean formalization](https://gist.github.com/ocfnash/19552b9031bff4888300777355b60991)
of the theorem that a topological group is isomorphic to a torus if and only if
it is compact, connected and abelian and has no small subgroups.
